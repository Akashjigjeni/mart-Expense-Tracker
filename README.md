# 🏠 Smart Expense Tracker (Data Science Project)

## 📌 Project Overview

The **Smart Expense Tracker** is a data science project that helps users analyze and manage their daily expenses.
It provides insights into spending habits by categorizing expenses and visualizing them using graphs.

This project is built using Python and demonstrates core data science concepts such as data cleaning, analysis, and visualization.

---

## 🎯 Objectives

* Track daily expenses in different categories
* Analyze total and category-wise spending
* Visualize expense distribution using charts
* Identify spending patterns and trends

---

## 📊 Features

* 📁 Load expense data from CSV file
* 📈 Total expense calculation
* 📊 Category-wise analysis
* 📉 Daily expense trend visualization
* 🥧 Pie chart for expense distribution

---

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib

---

## 📂 Project Structure

```
Smart-Expense-Tracker/

├── expenses.csv        # Dataset file

└── README.md          # Project documentation
```

---

## ▶️ How to Run the Project

1. Install required libraries:

```
pip install pandas matplotlib
```

2. Open Jupyter Notebook:

```
jupyter notebook
```

3. Run the notebook file:

```
expense_tracker.ipynb
```

## 📈 Sample Output

The project generates:

* Pie chart (expense distribution)
* Line graph (daily spending trend)
